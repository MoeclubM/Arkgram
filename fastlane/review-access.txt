Reviewer sign-in (real Telegram account)

1. Launch ArkGram and select Start Messaging.
2. On the phone number screen, select "Reviewer sign-in".
3. Enter the reviewer access code supplied privately in Google Play Console's App access instructions, then select Continue.
4. ArkGram creates a real Telegram device session for the dedicated review account. No SMS code, QR scanner or owner intervention is required.
5. Use the application's regular chats, contacts and settings. This is the normal Telegram backend, not the offline demo.
6. To sign out, open Settings, select More options, then Log out and confirm the logout.

The reviewer access code is not included in the application or this public file. Only the service URL is shipped. The account phone number, owner credentials and server Telegram session are not embedded in the application. If Telegram requires two-step verification, the application shows its regular password screen; any required password must also be supplied privately in Play Console.

AI and translation providers

External AI features use a provider, model and API key configured under Settings > ArkGram Settings > LLM. A real Telegram account does not supply external-provider credits. Review provider credentials and exact model instructions must be validated and supplied separately before claiming access to all features.

Additional offline demo

On the phone number screen, "Try offline demo" opens clearly labelled local sample chats, contacts and profile. No Telegram account is required. Demo messages are never sent to Telegram. This demo is supplementary and does not replace the real reviewer sign-in instructions above.
