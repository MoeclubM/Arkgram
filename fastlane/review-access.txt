Reviewer sign-in (real Telegram account)

1. Launch ArkGram and select Start Messaging.
2. On the regular phone number screen, enter the fictional review login alias supplied in Play Console and press Next. There is no separate review button.
3. On the verification code screen, enter the fixed 12-digit code supplied privately in Play Console. No SMS is sent. The server checks both the alias and the code before authorizing this device.
4. ArkGram creates a real Telegram device session for the dedicated review account. No SMS code, QR scanner or owner intervention is required.
5. Use the application's regular chats, contacts and settings. This is the normal Telegram backend, not the offline demo.
6. To sign out, open Settings, select More options, then Log out and confirm the logout.

The fixed review code is not included in the application or this public file and is not saved by the app. The app ships only a fictional review login alias and service URL. The real Telegram phone number, owner credentials and server Telegram session stay on the server. If Telegram requires two-step verification, the application shows its regular password screen; any required password must also be supplied privately in Play Console.

AI and translation providers

External AI features use a provider, model and API key configured under Settings > ArkGram Settings > LLM. A real Telegram account does not supply external-provider credits. Review provider credentials and exact model instructions must be validated and supplied separately before claiming access to all features.

Additional offline demo

Entering the fictional number +1 202-555-0100 on the normal phone number screen opens clearly labelled local sample chats, contacts and profile. No demo button is displayed. No Telegram account is required. Demo messages are never sent to Telegram. This demo is supplementary and does not replace the real reviewer sign-in instructions above.
