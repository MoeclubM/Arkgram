Make messaging yours.

ArkGram is an independent, unofficial messaging client using the Telegram API, developed by MoeClub. It is not affiliated with, endorsed by or sponsored by Telegram.

Use multiple accounts, configure translation and message filtering, and connect your own supported AI provider. Provider availability, charges and data handling are governed by the provider you choose.

Try the offline demo

On the phone number screen, choose “Try offline demo” or enter +1 202-555-0100. The sample account requires no verification code. Conversations are local examples, not a live Telegram account. Network messaging and calls require a real Telegram login.
