Account and data deletion

ArkGram · MoeClub · Updated 18 October 2026

ArkGram uses your Telegram account and does not create a separate MoeClub messaging account. Choose the action matching the data you want to remove. You do not need to install ArkGram or sign into this website to read these instructions.

Delete your Telegram account and cloud data

  1. Open Telegram’s official account deletion portal and authenticate directly with Telegram. Alternatively, follow Telegram’s official deletion instructions.
  2. Review Telegram’s explanation and confirm deletion there. This permanently removes the account and data covered by Telegram’s deletion process; it affects your use of that account in every Telegram client, not only ArkGram.
  3. For individual messages or synced contacts, use Telegram’s corresponding message/privacy controls instead of deleting the entire account. Existing copies held by other people or services are subject to their own controls and Telegram’s rules.

ArkGram’s Settings → Help → Account and data deletion links to this page. MoeClub cannot delete Telegram server data on your behalf. Uninstalling ArkGram, signing out or clearing its cache does not delete the Telegram account.

Delete data stored by ArkGram on your device

  • All local app data: use Android Settings → Apps → ArkGram → Storage → Clear storage, or uninstall ArkGram. This removes that installation’s local sessions, databases, preferences and saved provider keys, subject to Android/device backup and restore behaviour.
  • Cached media: use ArkGram Settings → Data and Storage → Storage Usage to clear media caches. Clearing media caches does not remove saved settings, API keys or Telegram cloud data.
  • Provider credentials: remove the key/provider in ArkGram’s LLM or translation settings. Also revoke the key at the provider if you want it disabled outside this installation.
  • Downloaded/exported files: remove files saved to Downloads, shared media or other external locations using your file manager. These files may remain after uninstall.
  • Offline demo: leave a sample conversation to discard messages you composed there. It has no remote account to delete. Demo settings use real app preferences; clear them as described above.

Delete information held by external translation or AI providers

Submit a deletion request or use the privacy controls provided by the actual endpoint operator. Request history, logs and model-related retention are governed by that provider, not ArkGram. Deleting the source message, clearing the app or revoking an API key does not itself remove a provider’s saved copies.

Request deletion of support correspondence

Email moecaa@telecom.moe with the subject “ArkGram support data deletion”, identify the previous correspondence and describe what you want removed. We use the request to locate and handle support information under our control. We may need to verify that the request relates to your correspondence and retain information required for applicable legal obligations or an unresolved dispute. We cannot use this process to delete Telegram or provider records.

Do not email Telegram verification codes, passwords, session files or API keys. If you have not contacted support and use only the offline demo, there is no support account or demo server record to delete.

账号与数据删除

ArkGram 使用你的 Telegram 账号，不另外创建 MoeClub 通讯账号。请选择与你要删除的数据对应的操作；阅读本页无需安装应用或登录本站。

删除 Telegram 账号与云端数据

  1. 访问 Telegram 官方账号删除门户，直接向 Telegram 完成认证，或参考 Telegram 官方说明。
  2. 阅读 Telegram 的提示并在其网站确认。该操作会永久删除其删除流程涵盖的账号和数据，并影响所有 Telegram 客户端中的同一账号。
  3. 只想删除个别消息或已同步的联系人时，请使用对应的消息和隐私控制，无需删除整个账号。其他收件人或服务已有的副本受其自身控制和 Telegram 规则约束。

ArkGram 的“设置 → 帮助 → 账号与数据删除”会打开本页。MoeClub 无法代你删除 Telegram 服务器数据；退出登录、清除缓存和卸载不会删除 Telegram 账号。

删除设备上的 ArkGram 数据

  • 全部本地数据：在 Android“设置 → 应用 → ArkGram → 存储 → 清除存储空间”操作，或卸载应用，移除该安装中的会话、数据库、偏好和提供商密钥；设备的备份恢复行为仍可能影响后续恢复。
  • 媒体缓存：在 ArkGram“设置 → 数据和存储 → 存储用量”清理。此操作不会删除偏好、API 密钥或云端数据。
  • 提供商凭据：在 LLM 或翻译设置中删除密钥或提供商。需要彻底停用密钥时，还应在提供商处撤销。
  • 导出文件：使用文件管理器单独删除 Downloads、共享媒体和其他目录中的导出或下载文件，它们可能在卸载后继续保留。
  • 离线演示：离开样例聊天会清空其中新输入的消息，没有远程演示账号需要删除；演示设置使用真实应用偏好，请按上述方式修改或清除。

外部翻译、AI 及支持邮件

外部提供商保存的请求、日志等需通过实际端点运营者的隐私控制或删除请求处理。删除原消息、卸载应用或撤销密钥，不会自动删除其已有副本。

如需删除我们控制的支持通信，请向 moecaa@telecom.moe 发送主题为“ArkGram support data deletion”的邮件，指出原通信及删除范围。我们可能需要核实通信归属，并保留适用法律义务或未解决争议所需的信息；此流程不能删除 Telegram 或外部提供商的数据。请勿发送验证码、密码、会话文件或 API 密钥。仅使用离线演示且未联系支持时，没有支持账号或远程演示记录需要删除。
